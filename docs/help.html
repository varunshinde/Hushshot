Help

Capturing

  • Capture full page (⌥⇧F / Alt+Shift+F): the whole page, top to bottom.
  • Visible (⌥⇧S): just what's on screen.
  • Area (⌥⇧R): drag a rectangle. Drag to the edge of the window to keep scrolling.
  • Element (⌥⇧E): click a part of the page; ↑ and ↓ pick the larger or smaller part around it.
  • Press Esc to cancel at any time. Change these keys at chrome://extensions/shortcuts.
  • Prefer one click? Settings → General → Clicking the toolbar icon → Captures the full page right away.

The result page

  • Download saves in the format shown. The ▾ next to it switches between PNG, PDF, JPEG and WebP, and remembers your choice.
  • Copy image and Copy text put the capture or all of its text on the clipboard.
  • Select text: drag a box over any part to copy just those words, including words in pictures and charts.
  • Crop: drag the edges or corners of the box, drag inside it to move it, or draw a new one. Click Done cropping (or press Enter). Every download and copy then uses the cropped area. Edit and Remove appear next to the tools afterwards.
  • Zoom: pinch on a trackpad, use the slider, or Fit page / Fit width. The percentage button shows actual pixels.
  • Long captures are split into parts or PDF pages between lines of text. Drag the blue lines to move a break.

Sharp mode and the "debugging" bar

Sharp mode draws the page again at 2× to 4× so text stays crisp. To do that it uses Chrome's debugging interface, so Chrome shows a bar saying LocalFullPageCapture is debugging the tab while a capture runs. It closes when the capture ends. You can turn Sharp mode off in Settings → General; captures then use your screen's resolution.

If something looks wrong

  • Part of an app page is missing (Gmail, Notion and similar): use Pick scroll area… in the popup and click the part that scrolls.
  • A header or banner repeats: Settings → General → Sticky headers → Hide. Some sites only make bars sticky while you scroll.
  • Images are missing or blurry placeholders: Settings → Advanced → Page loading → raise Wait for images.
  • The capture stops early on an endless-scroll page: that's the Longest page limit in Settings → Advanced, so it doesn't run forever.
  • Odd results with Sharp mode: Settings → Advanced → Method → Compatibility mode.
  • "This page can't be captured": Chrome doesn't let extensions capture its own pages, such as chrome:// pages, the New Tab page or the Chrome Web Store.

Still stuck? Open an issue on GitHub with the page address (if it's public) and a screenshot.
