# Security policy

Hushshot is built to keep everything on your computer: it makes no network requests, loads no remote code and asks for no host permissions. If you find a way around any of that, or any other security problem in the extension or on hushshot.app, please tell me privately first.

## Reporting a vulnerability

- **Preferred:** [report it privately on GitHub](https://github.com/varunshinde/Hushshot/security/advisories/new).
- **Or email:** hushshotcapture@gmail.com

Please don't open a public issue for security problems. Include the Hushshot version (Settings shows it), your Chrome version, what you did and what happened. I'll reply as soon as I can, fix confirmed problems first, and credit you in the changelog if you'd like.

## Supported versions

Only the latest version gets security fixes. The Chrome Web Store updates automatically; if you installed the zip by hand, update to the [latest release](https://github.com/varunshinde/Hushshot/releases/latest).

## Scope

- The extension in this repository and the published builds on the Chrome Web Store and GitHub Releases.
- The website at https://hushshot.app (served from `docs/` in this repository).

How the extension uses each permission is explained in [PERMISSIONS.md](PERMISSIONS.md).
